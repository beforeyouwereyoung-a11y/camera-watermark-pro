# 相机水印工具 Pro — 软件说明手册

> 版本 3.5.0 · Windows 免安装便携版（单文件版 / 文件夹版 二选一）

## 1. 软件定位

**相机水印工具 Pro** 是一个本地运行的批量照片水印工具。它可以给照片批量加上
EXIF 信息条、品牌 Logo、自定义文字水印、圆角阴影、模糊背景、社交平台裁幅等效果。

相比上一版，这一版的核心变化是：

| 项目 | 上一版 | 本版 |
| --- | --- | --- |
| 窗口形态 | 打开浏览器网页 | **WebView2 内嵌原生窗口** |
| 安装方式 | 目录式打包 | **单文件 exe + 文件夹版，都是免安装** |
| 效果预览 | 只能看原图 | **实时渲染水印效果 + 前后对比滑块** |
| 对比模式 | 两张图各自居中，会互相盖住 | **原图按原比例对齐到成片中照片的准确位置，分割线可按图片拖动**（v3.4.0） |
| 看细节 | 只能在小窗口里看 | **双击预览区铺满整个窗口**（v3.4.0） |
| 三栏宽度 | 固定 | **分界线可拖动 / 双击复位 / 方向键微调**，宽度被记住（v3.4.0） |
| 输出 EXIF | 丢失 | **完整保留拍摄参数** |
| 批量处理 | 不能中断 | **可随时取消，带进度与剩余时间** |
| 处理速度 | 单线程逐张 | **多进程并行（实测约 3 倍加速）** |
| 输出控制 | 只有质量 | **格式 / 长边 / 命名规则 / EXIF 开关** |
| 命名规则 | 只有 `{name}` | **`{name}` `{template}` `{index3}` `{date}`**，换模板不再被误判为「已存在」（v3.4.0） |
| 镜头型号 | 原样全打，竖构图会挤爆 | **超长自动截断成 `NIKKOR Z DX 50-250mm` 这种主体**（v3.4.0） |
| 水印方式 | 仅模板 | **模板 + 自定义文字水印（含平铺）** |
| 改模板 | 只能手写 JSON | **可视化编辑器：拖步骤 + 表单调参 + 实时预览** |
| 场景切换 | 每次重新调 | **预设方案：一键切换整套配置（内置 6 套）** |
| 品牌 Logo | 只能用内置的 | **可上传自己的 Logo，并可调大小/透明度/位置** |
| 处理结果 | 只报「处理完成」 | **结果面板：成片缩略图 + 原图对比 + 定位/另存** |
| 界面配色 | 固定浅色 | **浅色 / 深色 / 跟随系统** |
| 拖拽 | 不支持 | **可直接把文件夹 / 照片拖进窗口** |
| 输出目录保护 | 无 | **选完目录就提示，一键改为子目录，绝不覆盖原图** |
| `标准水印Pro` 版式 | 三级字重卡片，与 `标准水印2` 同族 | **「摄影作品展签」风格：白底展签、品牌粗体 / 型号常规、参数行、右下品牌 Logo**（v3.5.0 重做） |
| 换相机 | 品牌 / Logo 认不出就印错或空一块 | **按 EXIF 自动认品牌与型号，Logo 按品牌自动挑、自动裁白边、自动定尺寸**（v3.5.0） |
| 结果反馈 | 只报「处理完成」 | **明确报告输出目录 + 跳过原因** |

## 2. 系统要求

- Windows 10 / 11（64 位）
- 需要 **WebView2 运行时**（Win10/11 通常已预装；若窗口空白，见第 13 节）
- 不需要安装 Python，不需要联网

## 3. 启动方式（免安装）

本版提供**两种便携形态**，功能完全一样，按需二选一：

| | A. 单文件版 | B. 文件夹版 |
| --- | --- | --- |
| 形态 | 一个 `CameraWatermarkPro.exe` | 一个 `便携版-CameraWatermarkPro\` 文件夹 |
| 启动速度 | 慢（每次启动先解包到临时目录，约 3~6 秒） | 快（不解包，双击即用） |
| 适合 | 发给别人、放桌面 | 长期自用、放 U 盘 |

1. 把 `CameraWatermarkPro.exe`（或整个文件夹版目录）放到任意目录（例如 `D:\相机水印\`）。
2. **双击运行**即可，无需安装。

首次运行时，程序会在 exe 同目录自动创建这些文件夹：

```
D:\相机水印\
├─ CameraWatermarkPro.exe     ← 主程序
├─ config\                    ← 配置 / 模板 / 字体 / Logo（可自由修改）
│   ├─ config.ini
│   ├─ templates\             ← 水印模板（JSON）
│   ├─ fonts\                 ← 字体
│   └─ logos\                 ← 品牌 Logo
├─ input\                     ← 默认输入目录
├─ output\                    ← 默认输出目录
└─ logs\                      ← 运行日志
```

> **便携特性**：整个文件夹可以拷到 U 盘，换台电脑插上就能用，
> 配置和模板都跟着走。
> 如果 exe 所在目录不可写（例如放在 `C:\Program Files`），
> 程序会自动改用 `%LOCALAPPDATA%\CameraWatermarkPro` 存放配置，
> 界面上方的「数据目录」标签会显示实际位置。

### 4.1 界面主题（浅色 / 深色 / 跟随系统）

顶栏右侧有三档主题切换：

| 档位 | 说明 |
| --- | --- |
| 浅色 | 默认，适合白天 |
| 深色 | 适合夜间修图，降低屏幕刺眼感 |
| 跟随系统 | 跟着 Windows 的深色模式设置自动切换 |

## 5. 使用流程

1. 双击 exe 启动，等待窗口出现。
2. **先选一个预设方案**（可选）——点一下就把整套参数切好，省掉逐项调整。
3. 左栏「目录」里选择**输入文件夹**和**输出文件夹**（点「浏览」调出系统对话框）。
   如果两者选成了同一个，界面会立刻提示并给出一键修复按钮。
4. 中间栏会列出输入目录里所有支持的照片，点「刷新」可重新扫描。
5. 选择水印方式（模板 / 自定义文字），此时右栏会**立刻显示效果预览**。
   想比对前后差异就切到「对比」；想看细节就**双击预览区**铺满窗口（Esc 退出）。
6. 需要的话调整「画幅裁切」和「输出规则」（这两块默认收起，点标题展开），
   也可以上传自己的 Logo。
7. 在中间栏**勾选**要处理的照片（点「全选」可一次全勾）。
   「取消选择」只取消勾选，「清空全部内容」把列表 / 勾选 / 预览 / 进度一起清掉。
8. 点右下角「**开始处理**」，进度条会实时推进，并显示剩余时间。
9. 处理完成后**结果面板会自动弹出**，可以直接看成片缩略图、和原图对比、
   打开所在位置或另存为。

### 5.1 直接拖拽（推荐）

把**照片文件夹**或**一批照片**直接拖到中间栏的虚线框里：

- 拖进来的是文件夹 → 自动把该文件夹设为输入目录，并立即扫描；
- 拖进来的是照片 → 自动把它们的父目录设为输入目录，并**自动勾选这些照片**；
- 混着拖、一次拖多个也可以，程序会自动取公共父目录；
- 不支持的文件类型会被忽略，并在日志里列出名字。

> 拖拽依赖桌面窗口（WebView2）提供的真实文件路径通道。
> 如果在普通浏览器里打开界面，拖拽会提示改用「浏览」按钮——
> 这是浏览器安全限制，不是程序故障。
>
> 程序启动后会自动尝试接通这条通道，并**持续重试最多 60 秒**：
> 冷启动较慢的机器上，窗口刚打开时可能还拖不动，等一两秒即可。
> 若日志里出现「原生拖拽通道注册超时」，说明这台机器上 WebView2
> 没能完成初始化，此时请用「浏览」按钮选择文件夹，功能不受影响。

### 5.2 输出目录的安全规则（重要）

**输入目录和输出目录不要选成同一个。**

如果两个目录恰好相同，程序**不会覆盖你的原图**，而是自动把成片输出到：

```
<输入目录>\水印输出\
```

界面上会立刻用橙色文字提示这件事，处理完成后也会再说明一次。
你也可以一开始就把输出目录指到别的地方，语义更清楚。

> 之所以要这样设计：如果两个目录相同，成片路径会与原图路径完全重合，
> 在「不覆盖已存在文件」的设置下会导致**所有照片被静默跳过**，
> 而界面上仍然显示「处理完成」，看起来就像程序没干活。

另外，当输出目录位于输入目录内部时，扫描输入目录会**自动跳过输出目录**，
避免上一次的成片被当成新素材重复加工（出现 `水印输出\水印输出\` 这种套娃）。

### 5.3 预设方案（场景一键切换）

左栏最上方是「预设方案」，把**一整套参数**存成一个预设：模板、画幅裁切、
输出格式、命名规则、JPEG 质量、长边限制、EXIF 开关、覆盖开关、文字水印参数、Logo。

点一下卡片就切换整套配置，不用每次重新调。内置 6 套：

| 预设 | 适用场景 |
| --- | --- |
| 朋友圈竖版 4:5 | 微信朋友圈，竖构图 |
| 小红书 3:4 高清 | 小红书笔记，高清长图 |
| 横版宽幅 16:9 | 视频封面 / 横版展示 |
| 原图归档（带日期前缀） | 存档留底，文件名带拍摄日期 |
| 防盗图平铺水印 | 文字铺满整图，防止被盗用 |
| 网页轻量版 | WebP + 长边 1600，体积小、加载快 |

- 「另存为预设」把当前设置存成一个新预设，自己起名字
- 鼠标移到预设卡片上会出现删除按钮，可以删掉不想要的
- 预设存成 `config\presets\` 下的独立 JSON 文件，一个预设一个文件，
  方便备份，也可以直接拷给别人用

### 5.4 处理结果面板

处理完成后会自动弹出结果面板，把成片直接铺在界面上：

- 每张成片显示缩略图 + 状态标记（成功 / 跳过 / 失败）
- 顶部摘要写明统计、执行引擎和实际输出目录
- **只看成功**：一键过滤掉跳过和失败的条目
- 点任意一张成片打开**大图查看**，可以：
  - **对比原图**：切换显示处理前的原片，直观看出水印效果
  - **打开所在位置**：在资源管理器中定位到该文件
  - **另存为…**：把这张成片另存到别的地方

## 6. 两种水印方式

### 6.1 模板水印

内置 9 个模板，点击卡片即切换，右栏立刻出效果：

| 模板 | 说明 |
| --- | --- |
| 标准水印 | 经典 EXIF 信息条（机型 / 镜头 / 参数 / 时间 / 品牌 Logo） |
| 标准水印2 | 在标准水印基础上加圆角、阴影、留白，适合社交平台 |
| **标准水印Pro** | **「摄影作品展签」风格（v3.5.0 重做）**：纯白展签、上方照片 + 下方信息栏。信息栏左列是**品牌粗体 + 型号常规**（如 `NIKON` / `Z50 II`），第二行是参数（`24 mm · f/4 · 1/500 s · ISO 100`），最下行是日期；**右下角**按品牌自动放 Logo。**无分割线、不做照片修饰**，日期只到月日 |
| **画框Pro-中** | 明信片风格：照片四周留白框 + 照片柔影 + 1px 极淡描边。v3.4.0 起只保留「中」一档，细 / 粗已下线 |
| 背景模糊 | 模糊背景 + 居中机型与参数，氛围感强 |
| 尼康专用背景模糊 | 尼康风格，机型中的 Z 字高亮 + 模糊背景 |
| 右下角参数 | 极简，只在右下角显示拍摄参数 |
| 文件夹名+右下角参数 | 文件夹名 + 拍摄时间，适合归档 |
| logo居中 | 居中展示品牌 Logo |

> **从旧版升级（v3.5.0）**：`标准水印Pro` 换了整版版式，请手动删除 `config\templates\`
> 下的 **`标准水印Pro.json`** —— 程序只播种新模板、**从不删你目录里的文件**，同名模板
> 若你自己目录里已有旧版，新版**不会**自动覆盖它。删掉后重启程序，`标准水印Pro`
> 就会以新的展签版式重新播种。
>
> 如果你是从 **v3.4.0 之前**升上来的，另外还要删 `画框Pro-细.json` 与 `画框Pro-粗.json`
> （这两个模板自 v3.4.0 起已下线）。

- 「刷新列表」重新读取模板目录
- 「另存为新模板」把当前 JSON 存成一个新模板

> **底栏会自己排版（v3.3.0）**：`标准水印` / `标准水印2` 等**横排底栏**模板的底栏是
> 「左列两行 + 右列两行 + 中间 Logo」的结构。程序在绘制前会**先测量文字实际宽度**，
> 一旦发现左右两列会撞在一起（常见于竖构图，或 EXIF 里带很长的镜头型号），就自动
> 逐级降级：先把字号小幅缩小（1.0 → 0.85），再改成**单列左对齐、底栏按内容加高**，
> 最后才裁掉溢出部分。因此**任何画幅（含竖构图）都不会再出现文字与 Logo 互相堆叠**。
>
> （`标准水印Pro` 自 v3.5.0 起不再走这套横排底栏逻辑，它改成「固定比例展签」版式，
> 见下面那条。）
>
> **展签版式按照片宽度等比排版（v3.5.0）**：`标准水印Pro` 的所有字号与间距，都是按
> **照片实际渲染宽度 W** 取百分比的，而不是按「最终画布宽度」算。这样同一张照片无论
> 大小、无论什么画幅，展签的**视觉比例完全一致** —— 不会出现「小图上字很大、大图上
> 字很小」。
>
> **换相机也能用：品牌与 Logo 自动适配（v3.5.0）**：`标准水印Pro` 的品牌、型号、
> Logo 三者都会从照片 EXIF 里自动认出来：
>
> - **品牌**以 EXIF 的 `Make` 为准（这是标准字段）。比如 `NIKON CORPORATION` 会显示成
>   `NIKON`，`SONY` 显示成 `SONY`。
> - **型号**取 EXIF 的 `Model`，并**自动剥掉和品牌重复的前缀**，也会识别子品牌：
>   `NIKON Z50_2` 会显示成 `Z50 II`（去掉重复的 `NIKON`，并把 `_2` 规范成 `II`）；
>   索尼 `ILCE-7M3`、松下 `DC-S5M2` 这类型号位原样显示；`Canon EOS R6m2` 会去掉前缀
>   显示成 `EOS R6m2`；`PENTAX K-3 Mark III` 会把品牌认成 `PENTAX`（而不是 `RICOH`）；
>   `OM-1` 会把品牌认成 `OM SYSTEM`。
> - **Logo** 按认出的品牌去 `config\logos\` 里挑对应的 PNG，且会自动**裁掉图片自带的
>   白边**、再按品牌分档定尺寸（字标类品牌给更大的框），最后让它**贴着照片右边缘**摆放。
> - 认不出的品牌**不会报错、也不会印出 `None` 字样**，只是那一段留空。
>
> 日期格式：内置模板的日期已统一改成**只到月日**（如 `2026-10-04`），不再输出具体时分。
> 想改回带时间，把模板里的 `[:10]` 改回 `[:16]` 即可。
>
> **镜头型号会自动截断（v3.4.0）**：`NIKKOR Z DX 50-250mm f/4.5-6.3 VR` 会显示成
> `NIKKOR Z DX 50-250mm`。规则是「去掉括号注释 → 在第一个光圈标记处截断 →
> 超过 26 个字符再加省略号」，所以既保留了有用的型号信息，又不会挤爆底栏。
>
> **留白会跟着分辨率缩放（v3.4.0）**：`标准水印2` 的白框留白从固定 100 像素改成了
> 按画面高度取百分比。以前 100 像素在小图上是个很厚的白框、在大图上几乎看不见，
> 现在无论照片多大，白框的视觉厚度都一样，也修掉了「预览看到的构图和出片不一样」。

### 6.2 自定义文字水印

不写模板也能加水印，适合加署名 / 版权 / 日期：

- **水印文字**：支持占位符
  - `{name}` → 文件名
  - `{date}` → 拍摄日期
  - `{model}` → 相机型号
- **位置**：九宫格点选（九个位置任选）
- **字号**：按图片高度的百分比（1% ~ 12%），自动适配不同分辨率
- **不透明度**：5% ~ 100%
- **旋转**：-90° ~ 90°
- **文字颜色 / 描边颜色 / 描边宽度**：描边能保证文字在任何背景上都清晰
- **平铺水印**：勾选后文字铺满整张图，适合防盗图

### 6.3 自定义品牌 Logo

除了内置的相机品牌 Logo，你还可以上传自己的 Logo：

1. 点 Logo 区域的「**上传**」，选一张 PNG 或 JPG（PNG 支持透明背景，效果最好）。
2. 上传后在「**Logo**」下拉里选中它，成片上就会叠加这个 Logo。
3. 用三个控件微调：

| 控件 | 说明 |
| --- | --- |
| **大小** | 100% 约等于画面高度的 8%，可调 20% ~ 300% |
| **不透明度** | 5% ~ 100%，做淡雅水印就调低一些 |
| **位置** | 四角任选（左上 / 右上 / 左下 / 右下） |

- Logo 是**在裁切之后**叠加的，所以位置相对最终画幅，不会被裁掉。
- 上传的 Logo 存在 `config\logos\`，可以随时删除（鼠标移到下拉项上有删除按钮）。
- 想取消 Logo，把下拉选回「不使用」即可。
- 支持的格式：PNG / JPG / WEBP / BMP / GIF / TIFF，单张上限 16 MB。
  同名文件不会互相覆盖，会自动加序号（`logo.png` → `logo_2.png`）。
- 上传的文件会先校验再保存：**不是真图片、或超过 16 MB，会被直接拒绝，
  且不会在 `config\logos\` 里留下任何残留文件**。

## 7. 画幅裁切

一键裁成社交平台常用比例，居中裁切：

`原图` · `1:1` · `4:5` · `3:4` · `2:3` · `3:2` · `16:9` · `9:16`

## 8. 输出规则

| 选项 | 说明 |
| --- | --- |
| 输出格式 | 保持原格式 / JPG / PNG / WebP |
| 长边限制 | 例如填 2000，长边超过 2000 的图会等比缩小（只缩不放） |
| JPEG 质量 | 40 ~ 100，**默认 100**（v3.4.0 起；原来 95）。100 出来的文件会大一些，想小一点往左拖 |
| 命名规则 | 支持 `{name}` 原名、`{template}` 模板名、`{index3}` 三位序号、`{date}` 拍摄日期 |
| 保留 EXIF | **默认开启**，成片保留机型、镜头、光圈、快门、ISO、拍摄时间 |
| 覆盖已存在 | 默认关闭；关闭时遇到同名文件会「跳过」而不是覆盖 |

命名示例：填 `{name}_wm`，则 `DSC001.jpg` → `DSC001_wm.jpg`。

> **默认命名规则是 `{name}_{template}`（v3.4.0 起）**，出片形如
> `DSC_4821_标准水印Pro.jpg`。
>
> 为什么要加 `{template}`：以前默认值只有 `{name}`，同一张照片换模板后输出文件名
> **完全相同**，在「不覆盖已存在文件」的设置下会被判定为「已存在」直接跳过 ——
> 用户会以为「换了模板没生效」。加上模板名之后，换模板就会老老实实重新输出。
>
> 程序**只会**把「原封不动还是 `{name}`」的旧配置自动升级。如果你当初自己改过
> （比如 `{name}_wm`），它不会被自动改，需要你在命名规则里手动补 `{template}`。
>
> 模板名里可能带 `\ / : * ? " < > |` 这类不能进文件名的字符，程序会先做一次清洗
> 再拼进文件名，所以不用担心中文模板名或特殊符号导致写文件失败。

## 9. 实时预览与前后对比

右栏有三种预览模式：

- **效果**：显示加水印后的成品
- **对比**：左右分屏，**左边原图、右边效果**，中间白色分割线可左右拖动
- **原图**：只看原片

任何设置变化（换模板、改字号、换颜色、切裁切比例）都会**自动刷新预览**。

### 9.1 对比模式是「真的对齐」（v3.4.0 重做）

成片画布和原图尺寸**天生不一样** —— 模板里的画框、留白、投影都会把画布撑大。
比如同一张 1400×934 的原图：

| 模板 | 成片尺寸 | 宽高比 |
| --- | --- | --- |
| 标准水印2 | 2000×1615 | 1.238 |
| 画框Pro-中 | 1468×1138 | 1.290 |

旧版把两张图**各自**等比缩放居中塞进同一个盒子，结果就是「一张盖在另一张上面」，
分割线也因为按整个预览区计算而跟着错位。

现在程序会沿处理链路记录**「原图内容落在最终画布中的矩形」**，然后把左侧原图
按**原比例**摆到那个矩形上，并用居中裁切的方式对齐（所以带裁切的模板也能对齐）。
分割线改按**图片的实际渲染框**算百分比。

- 拖动白线：改变左右占比
- 点击图片任意位置：分割线跳到那个位置
- 中途换模板、换裁切：位置会**跟着重算**，不需要手动调

> 少数模板（自定义文字水印、拼接类）无法确定照片落点，这时会自动退回
> 「两张图整幅摆放」，至少保证分割线左右分布正确，不会出现互相遮挡。

### 9.2 放大看细节（v3.4.0 新增）

**双击预览区**，右栏会铺满整个窗口 —— 水印的字重、阴影、描边细节都能看清。
退出方式：再双击一次，或按 **Esc**。

### 9.3 三栏宽度可调（v3.4.0 新增）

三栏之间各有一条分界线：

| 操作 | 效果 |
| --- | --- |
| 拖动分界线 | 改变左右栏宽度 |
| 双击分界线 | 恢复默认宽度（左栏 350 / 预览栏 420） |
| 聚焦分界线后按 ← / → | 微调 12px；按住 Shift 微调 40px |

宽度会**记住**，下次打开还是你调好的样子。窗口变窄时会自动优先压缩预览栏、
再压缩左栏，保证中间的「待处理照片」始终可用。

## 10. 批量处理与进度

- 进度条实时推进，下方四个统计数字：已完成 / 成功 / 跳过 / 失败
- 处理过程中会显示「剩余约 X 分 Y 秒」
- 处理中「开始处理」按钮会变成「**取消**」，点击即可中断
  （当前正在处理的那一张会先跑完，之后立即停止）
- 处理完成后点「导出报告」，可下载**包含输出目录、跳过清单、失败清单**的文本报告

### 10.1 完成提示怎么读

完成消息会明确写出三件事，不再只报一句「处理完成」：

```
处理完成 —— 成功 12，跳过 0，失败 0 · 输出目录：D:\照片\水印输出
```

如果出现了「跳过」，消息会直接给出原因，例如：

```
处理完成 —— 成功 0，跳过 12，失败 0；
跳过原因：目标文件已存在（可勾选“覆盖已存在的文件”）（12 张）
```

- **成功 0 / 跳过 N**：说明目标文件已经存在，程序按设置没有覆盖。
  勾上左栏「覆盖已存在的输出文件」再跑一次，或把输出目录换成一个空目录。
- **失败 N**：多为原图损坏或格式异常，日志和导出报告里会写明具体原因。
- 右下角「**打开输出目录**」按钮会直接跳到本次任务实际使用的输出目录。

### 10.2 性能设置（多进程并行）

左栏「性能设置」可以控制处理速度：

| 选项 | 说明 |
| --- | --- |
| **并行进程数** | `自动`（推荐）/ `串行` / 手动指定 2~8。自动 = 取「CPU 核心数 − 1」，最多 8 |
| **小批量阈值** | 待处理张数少于此值时强制串行 —— 进程启动本身有开销，任务太少反而更慢 |
| **EXIF 缓存条数** | 缓存每张照片的元数据，翻页/重跑时不用重复调用 exiftool，默认 2048 |
| **预览长边** | 预览图先降采样到这个尺寸再渲染水印，默认 1400。调小更跟手，调大更精细 |

面板里还有两个按钮：

- **性能自检**：真的起一个子进程验证多进程是否可用，并给出建议进程数。
  如果环境不支持（企业策略、杀毒软件拦截），会明确告诉你原因，
  批处理会自动回退串行，**不会因此处理失败**。
- **清空 EXIF 缓存**：改过原图元数据后可以手动清一下。

实测参考：6 张 1600 万像素照片、标准水印2 模板，本机 16 核
—— 串行 16.1 秒，并行 5.1 秒，约 **3 倍**提速。

> 小提示：**文件夹版**的并行效率比单文件版更高。
> 单文件版每启动一个子进程都要把整个程序重新解包一次，
> 所以它的进程数上限被限制在 4；文件夹版没有这个开销，上限是 8。

## 11. 运行日志

## 12. 模板编辑器

模板本质上是一串「处理器」，每个处理器做一件事（裁切、加圆角、加水印、合并…）。
本版提供两种编辑方式：**可视化编辑器**（推荐）和**手写 JSON**（高级）。

### 12.1 可视化编辑器（推荐）

点左栏「**可视化编辑**」打开，界面分三栏：

```
┌──────────────┬──────────────────┬────────────────────┐
│  处理器库     │   当前流程        │   参数 + 实时预览    │
│  （可搜索）   │  （可加/删/排序）  │                    │
│              │                  │  ┌──────────────┐  │
│ 滤镜 / 生成器 │  ① rounded_corner │  │  参数表单     │  │
│ / 合并器      │  ② shadow         │  │  （按元数据   │  │
│              │  ③ watermark      │  │   自动生成）  │  │
│  点一下即添加  │  ④ …              │  └──────────────┘  │
│              │                  │  ┌──────────────┐  │
│              │                  │  │  效果预览     │  │
│              │                  │  └──────────────┘  │
└──────────────┴──────────────────┴────────────────────┘
```

用法：

1. **左栏**浏览或搜索处理器，点一下即追加到流程末尾。
2. **中栏**是当前流程，每个步骤卡片上可以**上移 / 下移 / 删除**。
3. **右栏**选中某个步骤后，会按该处理器的参数定义**自动生成表单**
   （数字框、滑杆、颜色选择、下拉、字体选择、Logo 选择、九宫格位置…），
   带「支持变量」标记的字段可以填 `{{vh(3)}}` 这类模板表达式。
4. 改任何参数，右栏预览会**自动重新渲染**，状态栏显示本次渲染耗时。
5. 满意后点「**保存为模板**」，起个名字即可；之后在左栏模板列表里就能选到。

> 为什么需要它：以前改模板必须手写 JSON，写错一个括号整个模板就废了。
> 现在 22 个处理器的参数都有元数据描述（名称、说明、取值范围、默认值），
> 表单据此生成，不需要记参数名。

### 12.2 高级：手写模板 JSON

左栏最下方「高级 · 模板 JSON 编辑器」：

- 直接编辑当前模板的 JSON
- 点「校验」检查 JSON 语法是否合法
- 点「应用到当前模板」保存并立即生效

模板是一串「处理器」的数组，每个处理器做一件事，例如：

```json
[
  { "processor_name": "rounded_corner", "border_radius": "{{vh(1)}}" },
  { "processor_name": "shadow", "shadow_radius": "100" },
  {
    "processor_name": "watermark",
    "left_top": { "processor_name": "rich_text",
                  "text": "{{ exif.CameraModelName }}", "color": "black" },
    "right_bottom": { "processor_name": "rich_text",
                      "text": "{{ exif.DateTimeOriginal[:16] }}", "color": "#242424" },
    "right_logo": "{{auto_logo()}}",
    "color": "white"
  }
]
```

模板里可以用：
- `{{ exif.字段名 }}` 读取 EXIF
- `{{vh(3)}}` / `{{vw(3)}}` 按图片高/宽的百分比计算尺寸
- `{{auto_logo()}}` 按相机品牌自动匹配 Logo

可用处理器一览：

| 类别 | 处理器 |
| --- | --- |
| 滤镜 | `blur` `resize` `trim` `margin` `margin_with_ratio` `crop` `rotate` `opacity` `rounded_corner` `shadow` `watermark` `watermark_with_timestamp` `simple_text_watermark` `tile_watermark` |
| 生成器 | `rich_text` `multi_rich_text` `gradient_color` `solid_color` `image` |
| 合并器 | `concat` `alignment` |

## 13. 常见问题

**Q：双击 exe 后窗口一直空白怎么办？**
说明系统缺少 WebView2 运行时。到微软官网搜索「WebView2 Runtime」下载安装
（Evergreen Standalone Installer）即可。Win10/11 通常已预装。

**Q：双击 exe 后没反应？**
先看任务栏托盘区有没有程序图标——点右上角关闭是把窗口收进托盘，程序还在运行。
再从托盘菜单选「打开主界面」。另外，重复双击只会唤出已有窗口（单实例）。

**Q：为什么有些照片读不到完整参数？**
原图本身可能没有完整 EXIF，或者图片被社交平台压缩过导致元数据丢失。

**Q：处理速度大概多快？**
取决于图片分辨率和模板复杂度。1600 万像素照片、标准水印2 模板，
单张大约 0.3 ~ 1 秒。可以在处理时看剩余时间估算。

**Q：拖拽文件夹时提示不支持拖拽？**
请确认用的是桌面窗口（双击 exe 打开的那个），而不是浏览器里的网页。
桌面窗口支持拖拽；浏览器受安全限制拿不到文件真实路径，只能用「浏览」按钮。

若在桌面窗口里仍然不行，请查看 `logs\` 里的日志：

| 日志内容 | 含义 | 怎么办 |
| --- | --- | --- |
| 原生拖拽已就绪（WebView2 真实路径通道） | 正常 | 直接拖 |
| 原生拖拽在第 N 次尝试后注册成功 | 正常，只是启动慢了点 | 稍等一两秒再拖 |
| 原生拖拽通道注册超时 | 本机 WebView2 没初始化成功 | 用「浏览」按钮，功能不受影响 |
| 查找拖拽区域失败：Main window failed to start | 窗口没能起来（多见于非交互式环境） | 用「浏览」按钮 |

程序会自动重试 60 秒，所以「刚打开时拖不动」属于正常现象。
另外请确认系统里装了 **WebView2 运行时**（Win10/11 一般自带；
缺失时程序会在启动时提示，也可从微软官网免费安装）。

**Q：输出目录里为什么没有我期待的文件？**
三种可能，按顺序排查：
1. 看完成提示——它会直接写出**实际输出目录**和**跳过原因**。
2. 「跳过」数字不为 0：说明目标文件已存在。勾上「覆盖已存在的输出文件」
   再跑一次，或换一个空目录。
3. 输入目录和输出目录选成了同一个：程序会自动输出到 `<输入目录>\水印输出\`，
   橙色提示和完成消息里都会写清楚。

**Q：为什么输出目录里多了一个「水印输出」文件夹？**
这是上面的安全规则在起作用，说明你把输入和输出选成了同一个目录。
这是正常行为，成片都在里面，原图没被动过。

**Q：启动有点慢？**
单文件版每次启动都需要把内置资源解压到临时目录，首次启动约 3 ~ 6 秒。
如果在意启动速度，改用**文件夹版**（不解包，双击即用）。

**Q：能放 U 盘里用吗？**
可以。整个程序目录拷走即可，配置、模板、Logo 都跟着走。

**Q：升到新版后，`标准水印Pro` 还是旧的样子？**
模板是同名文件，程序**不会**自动覆盖你自己目录里的模板。请删掉
`config\templates\标准水印Pro.json` 后重启程序，它会以新版展签版式重新播种。
（不想删也行：把当前模板另存为一个新名字，再删掉旧的。）

**Q：换了别的相机（索尼 / 佳能 / 富士…），`标准水印Pro` 会不会印错品牌？**
不会。品牌、型号、Logo 全部从照片 EXIF 自动识别，认不出的品牌会**留空而不是印错**。
要新品牌有 Logo，只要把该品牌的 PNG 放进 `config\logos\`，文件名带上品牌名即可
（例如 `leica_logo.png`），程序能自动对上。
详见第 6.1 节「换相机也能用：品牌与 Logo 自动适配」。
