========================================
 相机水印工具 Pro  v3.5.0
 免安装 · 完全离线 · 两种便携版
========================================

【两种便携版，选一个用】

A. 单文件版   CameraWatermarkPro.exe
   只有一个 exe，方便发给别人、放桌面。
   缺点：每次启动要先解包，第一次打开会慢几秒；
        批量处理时并行效率也比文件夹版低一些。

B. 文件夹版   便携版-CameraWatermarkPro\ 整个文件夹
   里面有 exe 和依赖文件。
   优点：启动快，双击即用，批量处理更快，适合长期自用或放 U 盘。

两种版本功能完全一样，数据都跟着程序走，随便选。


【怎么用】

1. 双击 CameraWatermarkPro.exe（文件夹版就进文件夹里双击）

2. 首次启动会在 exe 旁边自动创建这几个文件夹：
     config\   配置 / 模板 / 字体 / Logo / 预设（可自己改）
     input\    默认输入目录
     output\   默认输出目录
     logs\     运行日志

3. 界面上按这个顺序操作：
     左栏  →  （可选）点一个「预设方案」，整套参数一键切好
     左栏  →  选择「输入文件夹」和「输出文件夹」
     左栏  →  选一个模板，或者切到「自定义文字」自己写
     左栏  →  需要的话上传自己的 Logo，并调大小 / 透明度 / 位置
              （支持 PNG/JPG/WEBP/BMP/GIF/TIFF，单张不超过 16 MB；
                同名不会覆盖，会自动加序号）
     右栏  →  立刻能看到效果预览
              · 「效果」只看成片；「对比」是原图在左、成片在右，
                中间那条分割线可以左右拖，看哪边多一点随你
              · 双击预览区 = 把预览铺满整个窗口看细节，按 Esc 退出
     中间  →  勾选要处理的照片（点「全选」可一次全勾）
     右下  →  点「开始处理」

4. 处理完成后会自动弹出「结果面板」，成片缩略图直接铺在界面上：
     点任意一张 → 大图查看 → 可以和原图对比、打开所在位置、另存为


【把照片拖进来】

直接把「照片文件夹」或「一批照片」拖到中间的虚线框里，
程序会自动把该文件夹设为输入目录；拖的是照片就顺带自动勾选上。

小提示：程序刚启动时会自动接通拖拽通道，冷启动慢的机器上可能要等一两秒。
如果一直拖不动（日志里出现「原生拖拽通道注册超时」或
「Main window failed to start」），就用「浏览」按钮选文件夹，功能不受影响。
（在普通浏览器里打开网页版时拖拽也是不可用的——这是浏览器安全限制。）


【重要：输出目录不要和输入目录选成同一个】

如果两个目录选成一样，界面会**立刻**弹出提示，并给一个
「一键改为子目录」的按钮。点了之后成片会放到 <输入目录>\水印输出\，
原图绝不会被覆盖。你也可以一开始就把输出目录指到别的地方，更清楚。


【预设方案：换场景不用重新调】

左栏最上方有 6 套内置预设，点一下整套参数就切好了：

   朋友圈竖版 4:5     小红书 3:4 高清     横版宽幅 16:9
   原图归档（带日期前缀）  防盗图平铺水印     网页轻量版

自己调好的参数可以「另存为预设」，以后一键切回来。


【内置模板一览（共 9 套）】

   标准水印            经典 EXIF 信息条（机型/镜头/参数/日期 + 品牌 Logo）
   标准水印2           同上 + 圆角阴影留白，适合社交平台
   标准水印Pro         **摄影作品展签**风格（v3.5.0 起换新版式）：
                       纯白卡纸留白 + 照片下方一条信息栏。
                       左边一行「品牌 粗体 + 型号 常规体」，下一行拍摄参数（灰）；
                       右边「日期 + 官方 Logo」，Logo 按品牌自动匹配。
                       照片本身不做任何修饰（不圆角 / 不投影 / 不描边 / 不调色），
                       整张只有一种版式比例，横竖构图都不会走样。
   画框Pro-中          明信片风格：照片四周留白框 + 照片柔影 + 1px 极淡描边
   背景模糊            模糊背景 + 居中机型与参数
   尼康专用背景模糊      尼康风格，机型中的 Z 字高亮 + 模糊背景
   右下角参数          极简，只在右下角显示拍摄参数
   文件夹名+右下角参数   文件夹名 + 拍摄日期，适合归档
   logo居中            居中展示品牌 Logo

小提示：
* 竖构图照片不用担心水印文字打架 —— 程序会先量文字宽度，放不下就自动
  改成单列左对齐并把底栏加高，任何画幅都不会重叠。
* 内置模板的日期已经只到月日（如 2026-10-04），不带时分。
* 镜头型号太长会自动截断，只留「NIKKOR Z DX 50-250mm」这种主体，
  后面的光圈和括号注释会被去掉。


【界面可以按你的习惯调】

* 三条栏的分界处可以**左右拖动**改宽度，双击分界线恢复默认
  （拖动后预览栏能拉大，看效果更舒服）。
* 「待处理照片」右上角有两个不同的清除按钮：
    - 「取消选择」只取消勾选，"取消了哪些" 一看便知；
    - 「清空全部内容」把照片列表、勾选、预览、进度一起清掉，回到刚打开的样子。
* 左栏的「自定义 Logo」「画幅裁切」「输出规则」「性能」「高级」默认是**收起**的，
  点标题展开；展开/收起的状态会被记住，下次打开还是你上次的样子。
* 顶栏右侧可以切「浅色 / 深色 / 跟随系统」，选择同样会被记住。


【换相机也能用：品牌与 Logo 自动适配（v3.5.0 起）】

「标准水印Pro」是按 EXIF 里的厂商字段自动出字的，不写死尼康：

* 品牌文字取自 EXIF 的 Make 字段并做规范化
  （NIKON CORPORATION → NIKON、LEICA CAMERA AG → LEICA …），
  型号取自 Model 并自动去掉重复的品牌前缀。
  索尼 ILCE-7M3、富士 X-T5、松下 DC-S5M2、哈苏 X2D 100C、苹果 iPhone 15 Pro
  这类「型号里不带品牌」的写法都能正确拆开；
  理光映像出的宾得机身会显示为 PENTAX，不是 RICOH。
* 右侧 Logo 按品牌自动匹配（config\logos\ 里有什么就用什么）。
  徽标类（近方形，如尼康）按照片宽度的 5% 显示，
  字标类（细长，如索尼 / 佳能）按 9% 显示，
  这样两类 Logo 的视觉重量接近，右边缘也都严格对齐照片右边界。
* 目录里没有对应品牌的 Logo 时，会**干净地跳过**（不显示 Logo，
  日期顺移到照片右边界），不会报错、不会留下空白脏图。
  想自己补：把该品牌的图片丢进 config\logos\ 即可，文件名含品牌关键字就能命中
  （例如 om_system.png 对应 OM SYSTEM）。


【输出质量与命名规则（v3.4.0 起）】

* JPEG 质量默认改成 **100**（原 95），想小一点可以往左拖。
  注意：100 出来的文件会比 95 大一些。
* 命名规则默认改成 **{name}_{template}**，出片名形如
  DSC_4821_标准水印Pro.jpg。
  这样同一张照片换模板会重新输出，而不是被当成"已存在"跳过。
  可用占位符：{name} 原名 / {template} 模板名 / {index3} 三位序号 / {date} 拍摄日期。


【改模板不用写代码】

点左栏「可视化编辑」，左边挑处理器、中间排顺序、右边调参数，
右边还会实时显示效果。改完「保存为模板」就行。
（习惯手写 JSON 的话，左栏最下方仍保留原来的 JSON 编辑器。）


【界面太亮？】

顶栏右侧可以切「浅色 / 深色 / 跟随系统」，选择会被记住。


【两个提醒】

* 点窗口右上角的 X 是把程序收进右下角托盘，不是退出。
  要真正退出，右键托盘图标 → 退出。

* 需要保留拍摄参数的话，左栏「保留 EXIF 拍摄信息」保持勾选（默认已勾）。


【处理完提示「成功 0 / 跳过 N」是怎么回事】

说明目标文件已经存在，程序按设置没有覆盖它。
两种办法：
  * 勾上左栏的「覆盖已存在的输出文件」，再点一次「开始处理」；
  * 或者把输出目录换成一个空目录。
程序会在提示里写清楚跳过原因，不再只报「处理完成」。


【觉得处理慢？】

左栏「性能设置」里可以调并行进程数（默认「自动」，用多核并行处理，
实测比单线程快约 3 倍），里面还有「性能自检」按钮可以检查本机是否支持。

想再快一点的话，优先用**文件夹版**。


【想把整个软件放 U 盘带走】

文件夹版直接整个拷走就行；单文件版拷那一个 exe 也行。
配置、模板、Logo、预设都跟着走，换台电脑插上就能用。


【窗口打不开 / 一片空白？】

说明系统缺少 WebView2 运行时。
到微软官网搜索 "WebView2 Runtime"，下载 Evergreen Standalone Installer 安装即可。
Win10 / Win11 一般都已经预装。


【从旧版升级（请手动删除这三个文件）】

程序的规矩是「只往你的 config 目录播种新模板，从不覆盖、从不删除你目录里的
东西」。所以**同名模板换了版式，你那边不会被自动更新** ——
必须手动删掉旧的，新版才会重新播种进来。

1) 升级到 **v3.5.0** 必做：删掉下面这一个
   （旧版式：圆角 + 双层阴影 + 竖分隔线；不删的话你看到的还是旧样子）

       标准水印Pro.json

2) 从 v3.4.0 之前的老版本升上来的，还要删这两个
   （v3.4.0 起「画框Pro」只保留「中」一档，细 / 粗两档已下线）

       画框Pro-细.json
       画框Pro-粗.json

三个文件都在：<程序所在目录>\config\templates\

删完重启程序，模板列表就干净了；其余模板、配置、Logo、预设都不用动。

还有一处需要你确认：命名规则默认值从 {name} 改成了 {name}_{template}，
程序**只会**把"原封不动还是 {name}"的旧值自动升级。
如果你当初自己改过（比如改成了 {name}_wm），它不会被自动改，
需要自己在「输出规则 → 命名规则」里把 {template} 补进去，
否则同一张照片换模板会被当成"已存在"跳过。
